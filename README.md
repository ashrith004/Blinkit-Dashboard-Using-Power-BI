🛵 Blinkit Sales Analytics Dashboard

An interactive Power BI dashboard designed to analyze Blinkit retail sales performance across multiple outlets.
The project focuses on transforming raw sales data into actionable insights for business decision-making.

📊 Project Overview

This dashboard analyzes 50,000+ sales transactions to understand:

Overall sales performance

Outlet-level performance

Product category trends

Customer ratings and item demand

The dashboard provides a comprehensive view of sales metrics and business trends across Blinkit stores.

📁 Dataset

The dataset includes 50,000+ retail transactions with attributes such as:

🔍 Key Business Insights
🏪 Outlet Performance

Tier 1 outlets generate the highest revenue

Large outlets show significantly higher sales compared to small outlets

📦 Product Category Analysis

Snack foods and fruits & vegetables dominate sales

Low-fat products have slightly higher demand than regular products

📈 Sales Trends

Certain outlets consistently outperform others due to location and size

Higher item visibility positively impacts sales performance

⭐ Customer Ratings

Items with ratings above 4.0 show stronger sales patterns

Customer satisfaction plays a key role in repeat purchases

📊 Dashboard Features

The interactive dashboard includes:

Total sales overview

Sales by outlet size and location

Item category performance

Customer rating distribution

Item fat content analysis

Dynamic filtering using slicers
